Monotonic Stack: Explained with Example

November 4, 2025

Introduction #

A monotonic stack is a stack that maintains its elements in either increasing or decreasing order. It’s commonly used to solve problems like:

  • Next Greater Element
  • Daily Temperatures
  • Largest Rectangle in Histogram

Problem Statement #

Given an array \( \text{nums} \), return an array \( \text{res} \) where \( \text{res}[i] \) is the index of the next greater number to the right of \( \text{nums}[i] \). If none, return \(-1\).

Example:

nums = [2, 1, 2, 4, 3]

Expected output:

[3, 2, 3, -1, -1]

Core Idea #

We use a monotonically decreasing stack that keeps track of indices.

For every element \( \text{nums}[i] \), we:

  • Pop from the stack while \( \text{nums}[i] > \text{nums}[\text{stack.top()}] \)
  • Update \( \text{res}[\text{stack.top()}] = i \)

This gives us a one-pass \( O(n) \) solution.

Code (Python) # 

def next_greater_elements(nums):
    res = [-1] * len(nums)
    stack = []  # stores indices

    for i, num in enumerate(nums):
        while stack and nums[stack[-1]] < num:
            prev_index = stack.pop()
            res[prev_index] = i
        stack.append(i)
    
    return res

Complexity #

  • Time complexity: \( O(n) \)
  • Space complexity: \( O(n) \)

Each element is pushed and popped at most once.

Math Application #

In some problems, we may compare values using mathematical functions, like:

Let the slope between two points \( i \) and \( j \) be:

\[ \text{slope}(i, j) = \frac{y_j - y_i}{x_j - x_i} \]

This pattern is used in convex hull trick or maintaining max/min envelopes.

Conclusion #

Monotonic stacks help reduce many brute-force \( O(n^2) \) solutions to \( O(n) \). Recognizing when the “next greater/smaller” pattern appears is key to applying this technique.
