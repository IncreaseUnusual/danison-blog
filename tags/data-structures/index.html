Monotonic Stack: Explained with Example

Introduction #

A monotonic stack is a stack that maintains its elements in either increasing or decreasing order. It’s commonly used to solve problems like:

  • Next Greater Element
  • Daily Temperatures
  • Largest Rectangle in Histogram

Problem Statement #

Given an array \( \text{nums} \), return an array \( \text{res} \) where \( \text{res}[i] \) is the index of the next greater number to the right of \( \text{nums}[i] \). If none, return \(-1\).
